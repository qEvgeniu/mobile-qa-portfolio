# mobile-qa-portfolio
Pet-project: Mobile Automation QA Framework (Python + Pytest + Appium)

Привет! Это мой pet-проект по автоматизации тестирования мобильной игры BLACK RUSSIA (Android). 
Проект создан для демонстрации навыков построения архитектуры тестов, работы с Appium и интеграции с CI/CD.

## 🛠 Стек технологий
*   **Язык:** Python 3.x
*   **Фреймворк для тестов:** Pytest
*   **Инструмент автоматизации:** Appium (UiAutomator2)
*   **Паттерн проектирования:** Page Object Model (POM)
*   **Инструменты Android:** ADB
*   *(В планах: интеграция с GitLab CI / GitHub Actions и Allure Reports)*

## 🏗 Архитектура проекта (в разработке)
*   `config/` — настройки драйвера, capabilities и окружения.
*   `pages/` — Page Objects (классы, описывающие экраны игры и их локаторы).
*   `tests/` — непосредственно сами тест-кейсы (сценарии).
*   `utils/` — вспомогательные методы (например, снятие скриншотов, работа с ADB).

## 🚀 Как запустить (инструкция будет дополняться)
1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить эмулятор Android.
3. Запустить Appium Server: `appium`
4. Запустить тесты: `pytest tests/`

## 📌 Статус проекта
В активной разработке. Изучаю внутренности игры и настраиваю стабильные локаторы.
